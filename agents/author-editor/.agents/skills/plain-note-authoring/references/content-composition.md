# Content Composition

## Fit the note

Read enough local and note-wide context to identify:

- the note's purpose and audience;
- heading depth and section granularity;
- terminology, notation, spelling, and link style;
- whether nearby content is source-derived, explanatory, or editorial;
- the expected level of detail.

Match stable conventions without reproducing an obvious one-off formatting mistake.

## Design the fragment

Give the insertion one clear purpose. Choose only the structures needed to express it:

- prose for explanation or narrative;
- a list for genuinely parallel items or steps;
- a callout for a semantic role already supported by the content;
- a table for row-column data;
- LaTeX for mathematical notation;
- code fences for code or pseudocode;
- Mermaid or Excalidraw when relationships or spatial meaning require a visual.

Do not add a title, summary, prerequisites, examples, caveats, or conclusion automatically. Add them only when requested or needed to make the new content coherent.

## Preserve provenance and meaning

- Do not present newly generated explanation as handwritten or source-derived content.
- Preserve uncertainty in any supplied material used by the insertion.
- Separate a correction, modernization, or external explanation when merging it would misrepresent the existing source.
- Resolve new wikilinks before adding them; use plain text when no canonical target is known.
- Do not invent citations, examples, code behavior, equations, visual labels, or asset paths.

## Join with neighboring content

- Avoid repeating the preceding heading or opening sentence.
- Avoid a dangling pronoun or transition that depends on unstated content.
- Match grammatical tense and person when continuing prose.
- Match notation and defined terms already active in the containing section.
- Add a transition only when the insertion would otherwise read as disconnected.

Keep changes to the neighbors limited to structural separators. If coherence requires rewriting existing sentences, use the note-editing workflow as a separate operation.
